# introduction
This document will be split into two different types: Legacy (APIs under the www. or assetgame. domain) and New (APIs under api. domain).

For some APIs, differences will be mentioned in order to guide API differences expected in older programmes.

For site-only APIs (Legacy), details may be reluctantly be less detailed due to lack of resources. This may only affect for ROBLOX's transition to MVC as most of the old site behaviour were leaning towards the old WebForm system as of late 2013.

Undocumented APIs **will be mentioned**, though explicit details may lack.

For new open APIs (New), we may also sector them in different ways to include client related endpoints and other already documented early documents made by Roblox. This may only set a borderline here because we will also separate some of the API versions referring to the new & old (v1, v2) documented APIs that once were available.
